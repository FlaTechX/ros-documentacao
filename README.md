# rest-operation-system
Sistema de ecossistema completo para restaurantes visando a abordagem de casa inteligente(smart space)
## Requisitos
### Atendimento
* Cardápio digital
* Mapeamento de mesas
* Comandas por mesa
* Pagamento da comanda
### Cozinha
* Visualização do pedido em tempo real
* Notificação de pedido finalizado
### Gestão
* Produto
* Funcionário
### Entrega
* Integração com apps de delivery(Ifood, uber eats, ...)
### Externo
* Configuração do restaurante
* Definição usuários gerentes
* Configuração da rede de restauantes
